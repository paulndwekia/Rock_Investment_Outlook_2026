# FINTEL Project Scripts

This folder contains active project scripts.

Naming convention:
- Use clear functional names.
- Do not use `clean`, `fixed`, `final`, `repair`, `patch`, `v2`, or `v3`
  in active script filenames.
- Historical scripts and backups are intentionally not retained here.

- `build_website.py`
